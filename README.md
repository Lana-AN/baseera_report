# Baseera – Graduation Project Report (CS498)

LaTeX report for the Qassim University graduation project, based on the CS498 template.

## ملفات المشروع

| الملف | المحتوى |
|---|---|
| `00-main.tex` | الملف الرئيسي: الحزم، أسماء الفريق، صفحة الغلاف، وترتيب الفصول (**ما نكتب فيه محتوى**) |
| `00-prefatory-*.tex` | Abstract / Certificate / Dedication / Acknowledgement |
| `01-introduction.tex` | الفصل 1: Introduction |
| `02-literature.tex` | الفصل 2: Literature Review |
| `03-problem-analysis.tex` | الفصل 3: Problem Analysis |
| `04-system-design.tex` | الفصل 4: System Design |
| `05-appendix.tex` | الملاحق |
| `ref.bib` | كل المراجع (نضيف فيه فقط، ونستشهد بـ `\cite{key}`) |
| `figures/` | كل الصور والمخططات |

## البناء

- **Overleaf:** اجعل `00-main.tex` هو Main document والـ Compiler هو pdfLaTeX.
- **محليًا (Mac/Linux):** `make clean all` ثم يطلع الناتج في `build/thesis.pdf`.
